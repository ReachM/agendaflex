1 O que é o AgendaFlex?

O AgendaFlex é um sistema de agendamento online voltado para negócios de serviços. Imagine uma agenda inteligente que substitui aquele caderno de papel, o WhatsApp bagunçado e a planilha de Excel — tudo em um único sistema acessado pelo navegador.

Ele é um SaaS multi-empresa, o que significa que várias empresas diferentes podem usá-lo ao mesmo tempo, cada uma com seus próprios dados completamente separados e protegidos, como se cada empresa tivesse seu próprio sistema exclusivo.

📅
Agendamentos inteligentes

Crie, edite e cancele agendamentos com detecção automática de conflitos de horário. Nunca mais dois clientes no mesmo horário.

🌐
Link público de agendamento

Seus clientes agendam sozinhos pelo celular ou computador, sem precisar ligar ou mandar mensagem para você.

💰
Controle financeiro

Veja quanto entrou, quanto saiu, qual serviço dá mais lucro e quais são seus clientes mais fiéis.

✅
Checklists de atendimento

Monte listas de etapas para cada tipo de atendimento. Ideal para oficinas e clínicas que precisam documentar o serviço realizado.

4 Como instalar o sistema

Esta seção é para a pessoa técnica (desenvolvedor) que vai configurar o sistema. Se você é o usuário final, pule para a seção "Primeiro acesso".

O que você precisa ter instalado no computador

  • Node.js versão 18 ou mais novo — é o motor que roda o sistema
  • PostgreSQL — o banco de dados (ou Docker para subir automaticamente)
  • Git — para baixar o código

Passo a passo da instalação

  • 1
    Baixe o código do projeto

    Abra o terminal e execute os comandos abaixo:

# Baixa o projeto para seu computador git clone https://github.com/ReachM/agendaflex cd agendaflex # Instala todas as dependências necessárias npm install
  • 2
    Configure as variáveis de ambiente

    Crie o arquivo de configuração copiando o exemplo:

cp .env.example .env

Abra o arquivo .env e ajuste as três variáveis:

# Endereço do banco de dados DATABASE_URL="postgresql://agendaflex:agendaflex@localhost:5432/agendaflex?schema=public" # Chave secreta para gerar tokens de login (troque por algo longo e aleatório!) AUTH_SECRET="coloque-aqui-uma-senha-longa-e-aleatoria-com-32-ou-mais-caracteres" # URL onde o sistema vai rodar NEXT_PUBLIC_APP_URL="http://localhost:3000"
  • 3
    Suba o banco de dados com Docker (opcional, mas recomendado)

    Se tiver Docker instalado, isso sobe o PostgreSQL automaticamente:

docker compose up -d
  • 4
    Crie as tabelas e os dados iniciais

    Esses comandos preparam o banco de dados com a estrutura e os dados de teste:

# Cria todas as tabelas no banco npm run db:migrate # Insere os dados iniciais (planos, empresas de teste, usuários) npm run db:seed
  • 5
    Inicie o sistema

    Depois de tudo pronto, inicie o servidor de desenvolvimento:

npm run dev
Sistema rodando! Acesse http://localhost:3000 no seu navegador. O sistema estará disponível.
Atenção: Após instalar e colocar em produção, troque imediatamente o AUTH_SECRET por uma senha forte e mude as senhas das contas de teste. As senhas padrão são públicas.

5 Primeiro acesso

Ao abrir o sistema no navegador, você verá a tela de login. Digite seu e-mail e senha e clique em entrar.

7 Agendamentos

O agendamento é o coração do sistema. É aqui que você registra quando um cliente vai ser atendido, por qual profissional, e quais serviços serão realizados.

Como criar um agendamento

  • 1
    Acesse "Agendamentos" no menu

    Clique no botão "Novo agendamento".

  • 2
    Escolha o cliente

    Selecione um cliente já cadastrado ou crie um novo na hora.

  • 3
    Escolha o profissional e o horário

    Selecione quem vai atender e defina a data e hora. O sistema avisa automaticamente se há conflito de horário.

  • 4
    Adicione os serviços

    Escolha um ou mais serviços que serão realizados. O preço de cada serviço é registrado no momento do agendamento — mesmo que você altere o preço depois, o histórico fica preservado.

  • 5
    Salve

    O agendamento aparece na agenda e fica disponível para o profissional responsável.

O que é "snapshot de preço"? Quando você salva um agendamento, o sistema guarda o preço dos serviços naquele exato momento. Assim, se você aumentar o preço de um serviço depois, os relatórios financeiros de meses anteriores continuam corretos e não são afetados.

Status de um agendamento

StatusSignifica
AgendadoCliente confirmado, aguardando a data
ConcluídoAtendimento realizado com sucesso
CanceladoAgendamento cancelado pelo cliente ou pela empresa

8 Clientes

O cadastro de clientes guarda todas as informações de quem usa seus serviços. Cada cliente é vinculado à sua empresa — outra empresa no sistema não tem acesso aos seus clientes.

O que é possível cadastrar

CampoO que é
NomeNome completo do cliente
TelefoneNúmero para contato e lembretes
E-mailEndereço de e-mail do cliente
Campos personalizadosQualquer informação extra que sua empresa precise (ex: número do CPF, nome do pet, placa do veículo)

Histórico do cliente

Ao abrir o cadastro de um cliente, você vê todo o histórico de agendamentos dele na sua empresa: quais serviços realizou, quando, com qual profissional e quanto pagou. Isso ajuda a identificar clientes fiéis e frequência de retorno.

9 Serviços

Os serviços são o que sua empresa oferece: corte de cabelo, consulta médica, troca de óleo, banho e tosa, etc. Cada serviço tem um preço e uma duração estimada.

Como cadastrar um serviço

  • 1
    Acesse "Serviços" no menu

    Clique em "Novo serviço".

  • 2
    Preencha nome e preço

    Dê um nome claro para o serviço e defina o valor cobrado.

  • 3
    Defina a duração estimada

    Em minutos. Isso ajuda na organização da agenda.

  • 4
    Adicione campos personalizados se precisar

    Por exemplo, uma clínica pode querer registrar se o serviço é "presencial" ou "telemedicina".

Dica: Você pode alterar o preço de um serviço a qualquer momento. Os agendamentos já realizados continuam com o preço original registrado — o histórico financeiro não é afetado.

10 Profissionais

Os profissionais são as pessoas da sua equipe que realizam os atendimentos: médicos, cabeleireiros, mecânicos, etc. Cada agendamento é vinculado a um profissional específico.

O que você pode gerenciar

👤
Cadastro

Nome, informações de contato e campos personalizados (especialidade, CRM, etc.)

📋
Agenda

Veja todos os agendamentos de um profissional específico e gerencie a disponibilidade

Quando um agendamento é criado, o sistema verifica automaticamente se aquele profissional já tem um atendimento no mesmo horário — se tiver, alerta antes de confirmar.

11 Página pública de agendamento Plano Pro e Max

Com o plano Pro ou Max, sua empresa ganha uma página própria na internet onde seus clientes podem agendar serviços sozinhos, sem precisar ligar ou mandar mensagem.

Como funciona para o cliente

  • 1
    Cliente acessa o link da sua empresa

    A URL segue o formato: seu-dominio.com/book/nome-da-sua-empresa

  • 2
    Escolhe o serviço desejado

    Vê a lista de serviços disponíveis com preços e duração.

  • 3
    Escolhe data e horário

    Só aparece horários que estão realmente disponíveis — o sistema verifica em tempo real.

  • 4
    Preenche os dados e confirma

    Nome, telefone e qualquer campo extra que você tiver configurado.

  • 5
    Agendamento aparece no seu painel

    Você recebe o novo agendamento automaticamente, sem precisar fazer nada.

Benefício: Clientes podem agendar a qualquer hora do dia, inclusive fora do seu horário de trabalho. Isso reduz o trabalho de recepção e aumenta o número de agendamentos.

O que você vê no módulo financeiro

RelatórioO que mostra

Receita por mêsQuanto sua empresa faturou em cada mês, em gráfico

Como registrar uma receita ou despesa

  • 1
    Acesse "Financeiro" no menu

    Disponível apenas no plano Max.

  • 2
    Clique em "Nova entrada"

    Escolha se é uma receita (dinheiro que entrou) ou despesa (dinheiro que saiu).

  • 3
    Preencha o valor e a descrição

    Ex: "Aluguel do espaço" como despesa, ou o sistema pode registrar automaticamente a partir dos agendamentos concluídos.

Automatismo: Quando um agendamento é marcado como "Concluído", o valor dos serviços já pode ser contabilizado automaticamente como receita, sem precisar registrar manualmente.

13 Checklists de atendimento Plano Max

Os checklists permitem criar listas de etapas que devem ser seguidas durante um atendimento. É como um roteiro de serviço que garante qualidade e rastreabilidade.

Exemplo de uso: Oficina mecânica

Checklist: Revisão de 10.000 km
☑ Troca de óleo do motor
☑ Verificação de filtros
☑ Calibragem dos pneus
☐ Teste de freios
☐ Verificação de fluidos

Como criar um checklist

  • 1
    Acesse "Checklists" no menu

    Clique em "Novo checklist".

  • 2
    Dê um título ao checklist

    Ex: "Revisão completa" ou "Consulta de retorno".

  • 3
    Adicione os itens

    Cada item é uma etapa do atendimento que precisa ser realizada e confirmada.

  • 4
    Vincule ao agendamento

    Quando o profissional abre um agendamento, ele vê o checklist e vai marcando cada etapa concluída.

Benefício: O histórico do checklist fica salvo junto ao agendamento. Você pode ver depois exatamente o que foi feito em cada atendimento, quando e por quem.

16 Como seus dados são protegidos

O AgendaFlex foi construído com segurança como prioridade desde o início. Aqui está, de forma simples, como cada camada de proteção funciona:

🔐
Isolamento de dados por empresa

Cada empresa tem seus próprios dados completamente separados. É como se cada negócio tivesse um cofre próprio — uma empresa jamais consegue ver os dados de outra, mesmo estando no mesmo sistema.

🎫
Login seguro com token

Quando você faz login, o sistema emite um token criptografado (JWT). Esse token carrega sua identidade e os dados da sua empresa de forma segura. Sua senha nunca é enviada em nenhuma requisição após o login.

🛡
Senhas criptografadas

As senhas nunca são armazenadas em texto claro. O sistema usa bcrypt, que transforma sua senha em um código irreversível. Nem os próprios desenvolvedores conseguem saber sua senha.

⚡
Proteção contra ataques

O sistema tem proteções contra CSRF (tentativas de ação forçada) e Rate Limiting (bloqueio de tentativas repetidas de invasão).

Conformidade com LGPD: O AgendaFlex foi construído respeitando a Lei Geral de Proteção de Dados. Os dados dos seus clientes pertencem à sua empresa e são tratados com sigilo.

20 Glossário — termos do sistema explicados

SaaS (Software como Serviço)
Um sistema que roda na internet e é usado por várias empresas ao mesmo tempo, como se cada uma tivesse seu próprio espaço separado. Você acessa pelo navegador, sem instalar nada.
Multi-tenant
Significa que várias empresas (tenants = inquilinos) usam o mesmo sistema, mas cada uma vê apenas seus próprios dados. É como um prédio de apartamentos: cada morador tem sua chave e vê só o seu apartamento.
Tenant
Cada empresa cadastrada no sistema. O Salão Bella é um tenant. A Clínica Vida é outro tenant. Cada um tem seus dados completamente isolados.
JWT (Token de sessão)
Um código criptografado que o sistema emite após o login. Ele funciona como um crachá digital — prova quem você é e a qual empresa pertence em cada requisição feita ao sistema.
Plan Guard
O "porteiro" do sistema. Antes de deixar você usar uma funcionalidade, ele verifica se o plano da sua empresa inclui aquele recurso. Se não incluir, bloqueia com uma mensagem clara.
Snapshot de preço
Cópia do preço de um serviço no momento em que o agendamento foi criado. Isso garante que, se você mudar o preço depois, os agendamentos antigos continuem com o valor correto nos relatórios.
RBAC (Controle de acesso por papel)
Sistema de permissões onde cada usuário tem um papel (Admin, Profissional, Super Admin) e cada papel tem acesso a um conjunto específico de funcionalidades.
DRE (Demonstração de Resultado do Exercício)
Relatório financeiro que mostra o resultado do negócio: quanto entrou de receita, quanto saiu de despesa e qual foi o lucro em um período.
LGPD (Lei Geral de Proteção de Dados)
Lei brasileira que regula como os dados pessoais de clientes podem ser coletados, armazenados e usados. O AgendaFlex foi construído para respeitar essa lei.
Slug
A parte do endereço (URL) que identifica sua empresa na página pública de agendamento. Ex: /book/salao-bella — "salao-bella" é o slug.
Seed
Processo que popula o banco de dados com dados iniciais de exemplo (planos, empresas de teste, usuários). Roda com o comando npm run db:seed.
ORM (Mapeador de Objeto-Relacional)
Ferramenta (Prisma, neste caso) que permite ao código conversar com o banco de dados de forma segura e organizada, sem escrever comandos SQL diretamente.
